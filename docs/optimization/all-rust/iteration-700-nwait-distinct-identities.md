## 当前已运行的范围

一个真实 Rust Manager、一个本地 SOCKS 入口建立 A/B 两条独立 IKE/ESP/IMS 关联。模拟卡按实际选中 ICCID 返回不同 IMSI、ISIM 元数据、SMSC 及 IKE/IMS 认证材料；对端依据真实解密的身份冻结各关联，独立验证认证摘要和密钥使用。

主场景运行 33.15 秒通过：初始独立 APDU 读出原 B；启动 A 和 B；A 原关联收到续期挑战，实际切回 A 的 USIM AUTH 被屏障持有，此时 B 收到真实 OPTIONS 后返回匹配的 200；释放后 A 同代续期成功。分别停止后，持续持有的实际 Manager Runtime 的已有 watch 必须已返回 OriginalRestored，再用 Gate 真准入/释放探针和独立 APDU 读回证明占用已释放、原 B 的 EID/ICCID/IMSI 等身份恢复。最后才允许 teardown，不让 Runtime 析构替错误的 Stop 补做清理。

该运营商默认使用 USIM 完成 IKE、IMS 和 refresh AUTH；ISIM 在本场景仅证明元数据读取，不声称 ISIM 私有鉴权通过。未发业务短信，SMSC 只证明卡片读取及隔离，不授网络短信路由验收。

此外，699 保活三项、原卡片生产夹具一项、原 Manager 收发及重建一项均通过，共六个不同测试名称；原流程使用旧夹具默认值，仍保持兼容。完整回归已与 699 的策略改动一起验证，1894.226 秒正常退出，不继承 698 的全量结果。六项定向与全量存在重合，不相加。八个默认忽略的专属子进程入口不计通过，库的 298 项历史通过只适用于未变的库源码。
