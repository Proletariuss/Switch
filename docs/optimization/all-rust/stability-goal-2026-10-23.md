## 保持的安全与兼容约束

- 业务后端由 Rust 持有；系统桥和成熟编解码 FFI 一起审议边界。
- EVS 优先，AMR-WB 后备；不重新启用 AMR-NB/PCMA。
- 保持用户设置的代理/fake-IP 路径和自定义 ePDG/port 优先级。
- 外部操作提交结果未知时不自动重放；超时不等于退出或物理释放。
- 账本压缩必须设计旧 ID 拒绝/退役协议；不能直接清空回执解除容量限制。
- 除明确识别的可再生缓存外不删除源码、依赖、证据和恢复数据。
