# Iteration 506：串口短信的精确会话绑定与原生选路

2026-10-16。本轮源码实现、完整软件门禁及 Rust 生产编译检查通过。完整串口生命周期、串口 eSIM 和最终 Go 退出仍未完成。

## 本轮变化

原生串口短信任务改为绑定执行器随机实例、串口连接会话和 SIM 代次。关闭重开、进程重建或换卡后，旧任务不能继承新连接；旧纯代次和 Go 包装令牌不自动升级。准备、业务预约等待后、actor 排队准入、实际 CMGS、prompt 数据提交及分段边界共同检查。

若 CMGS 已发出而待提交数据的身份失效，关闭并隔离对应会话、撤销排队工作，不把下一条 AT 当成旧短信数据，不发送 ESC 或自动重放。最后一段提交后、确认前发生身份变化时，保留已观察的分段结果，整体仍按未确认处理。

配置为串口后，默认及显式 DJI 短信选路、就绪状态和号码由 Rust actor 提供；未初始化、SIM 状态未知或 radio 仍绑定旧连接时不回退到 Go。号码缓存仅接受同会话、同 SIM 的查询结果；换卡后清空。正常 QSIMSTAT 插卡证据继续支持，已知 PIN 锁定仍拒绝。既有读卡器/模块 IMS 优先级及双通道选择冲突保留。

Go 管理模式停止新签发旧串口短信能力，旧兼容记录清理继续保留。旧 Go 包装任务在 Go 退出后仍恢复为 unknown，新原生任务则等待其保留的执行者完成；完整进程恢复继续处理所有未完成任务。
