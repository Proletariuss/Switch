# Iteration 502：原生 USB 状态、短信路线与 3.41 发行

2026-10-14。按用户本轮“给我生成DMG”的明确要求完成发行验证；此前 3.40 安装包仅包含 Iteration 501。本轮源码保留完整非传真功能，不进行真实号卡操作、短信发送或呼叫测试。

## 实现及兼容边界

Rust 接管已选择 USB 传输的设备状态、健康观察、短信设备事实及 USB 直接发信的准备、复核、提交。真实读取仍使用同一 USB owner、射频保留与实际任务完成证明；页面请求取消不会提前释放物理工作。未打开设备的硬件描述通过受限 ioreg 子进程查询，设置输出和时间上限，串行复用观察，不把发现设备当作 SIM 就绪或 IMS 注册成功。

设备状态与描述保留精确观察代次直到最终 HTTP 发布。兼容 Go 响应迟到时重新核对当前传输选择；设备切换后不再返回旧设备或卡片身份。明确换卡或拔卡会撤销旧短信准备记录；普通 AT 错误不推断换卡。QCCID 在内部身份比较时去除引号，公开 JSON 保留兼容格式。

短信中心补齐原生模块 IMS 的已注册事实和当前绑定。已选择 USB 时使用原生事实，串口及尚未选择传输仍走现有兼容路径。直接 USB 发送复用原有账本、绑定编码和唯一提交 claim；结果未知保持冻结，不自动重放，持久化格式不变。准备阶段的设备错误恢复准确分类，不再误报存储故障。

健康状态中的 eSIM 路由可用性依赖真正完成的 CFUN 启动策略及当前设备绑定；只配置设备或放弃等待不授予可用状态。缓存仅服务展示，不能替代发送前身份核验。
