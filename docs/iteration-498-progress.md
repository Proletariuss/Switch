# Iteration 498：普通读卡器 Rust 接管与 N待旧执行者退出

2026-10-14。普通读卡器的公开 VoWiFi 启停、状态、短信和语音已接入保留生命周期的 Rust Service/LiveDriver。Go N待生产管理器、卡片调度和旧回调代码删除；SwiftUI、系统桥、既有数据格式、EVS 优先/AMR-WB 兼容策略保留。模块 VoWiFi 仍由 Go 协调，本轮没有完成整个全 Rust 目标。

## 生产接管

- 普通 reader 默认通过实际主 HTTP 路由进入 Rust，覆盖当前卡片身份、IKE/ESP、受保护 IMS 注册、双向短信、通话、续期和清理。设备快照空闲状态也读取原生 Service，不再回读已退役的 Go reader 状态接口。
- 共享通话及 reader 前缀 USSD 保留历史模块别名，只有真实 Go module claim 才转发到模块会话。旧代原生会话或未知归属不会转给另一个 owner。混合会话列表通过独立内部只读路径补充模块状态；Go 不可用时明确报告缺失观察。
- Go 旧 N待 manager/runtime/card/store 客户端及分支退役。仍被模块使用的认证 RPC 传输迁入中性 `internal_rpc_client.go`，原有错误语义保持；未把删除代码复制到源码参考目录。19 条已登记的旧 N待内部 HTTP 契约移除，仍使用的 reader-operation 和 native inventory 入口保留。
- N待实际 worker 补回安全诊断事件，绑定随机关联标识和真实会话代次，使用固定原因码。只在实际清理完成后记录 complete；未确认清理不能生成成功事件。

## 蓝牙与退出

Swift 记录准确的 CBPeripheral 对象、连接代次及关闭操作。实际 didDisconnect 和在途卡片任务均完成后才产生关闭回执；逻辑断开、超时、取消、旧连接或新连接同名均不能替代它。Rust 在连接和读取元数据时冻结该身份，卡片工作流保留绑定，N待父归属只接受匹配当前卡片代次的物理证明。

迟到回执仍可在停止接纳新工作后完成清理，HTTP 调用取消不会丢掉真实任务。主进程保持 BLE 观察直到原生会话清理结束。交叉审查发现原生 reader loss 仍可能无条件等待 Go；现由物理转换时同锁捕获的 legacy 归属决定是否等待。缺失或读取失败不视为无归属；真正的旧 Go owner 仍需原 producer 退出证明。

另一项修复隔离了 Go 子进程退出的短信恢复范围。原逻辑把仍由 Rust 执行的设备短信标为 unknown，导致之后的真实 accepted 无法入账。现在复用实际发送绑定分类，仅恢复 Go 兼容提交，N待原生队列不受该事件影响。整个 Rust daemon 启动时仍恢复所有中断任务，未知结果不自动重发。

## 运营商配置等价修复

审查发现，原生配置先编译原始模板、后应用用户覆盖，Rogers 等模板中的 DH5 会提前拦截有效覆盖。现分别处理 IKE/ESP：显式参数先验证并选用，只解析未被覆盖的一侧。原始严格模板编译和无效显式参数仍拒绝。

会话配置遵循旧 Go 的 exact 模板适用条件；非 exact 时使用旧后端真正可执行的通用方案。旧 Go 默认 IKE 报文曾包含 DH15/DH2，但实际密钥交换只实现 DH14，且没有 INVALID_KE 切组恢复。本次保序保留可执行的四个 DH14 proposal、保留全部六个 ESP proposal。删除不可执行项并重新编号会改变原始 IKE 报文，不能声称所有原始 wire 字节相同。显式算法列表没有被静默删减。

独立 Go 测试调用真实 effective-config 与编码器，导出 2,730 条全注册表及覆盖策略用例；Rust 对实际会话配置、Go 可执行 DH14 投影及完整 ESP 报文逐项比较，零差异。此项已加入持续迁移门禁，不等于 2,730 张真实号卡或运营商注册验收。此前对 UDP/证书的审阅疑点已纠正：Go 现有生产注册同样限 TCP，macOS 原生证书验证已接入系统信任与签名校验。

重要覆盖包括：实际主 HTTP 鉴权/路由到本机模拟 IKE/IMS/SMS/语音 peer，默认 owner 不使用测试 readiness 开关；EVS 发话与 AMR-WB 来话、RTP/PCM、短信耐久入库和 RP-ACK、同连接刷新与重连；真实 BLE Unix 桥和模拟系统回调；保留任务的迟到物理证明；在实际 RP-DATA 发出后、网络确认前执行生产 Go-exit 恢复 helper，之后仍正常 accepted/归档且不重发。

旧 IPC 测试迁到现用 typed Store/native consumer 与有效公共路由，保留持久化、崩溃恢复、鉴权和损坏失败关闭覆盖。新增实际 SIP MESSAGE 解码后归档失败无法取得 NativeSmsCommit 的证明，不能给远端成功 RP-ACK。20 个已退役或未登记路径的 180 次真实 HTTP 组合均拒绝且不写盘。

初轮全量测试中 9 项失败为仍期待旧内部路由或旧归属计数的测试，原日志保留。另保留中间夹具的 Unix 半关闭、socket 路径过长、缺少查询参数及空 YAML 解析失败，不将这些中间日志改称通过。最终结果以最终全量门禁和独立差分日志为准。
